# Day 8.2 - Cross Validation

## Objective

Evaluate the model using multiple train-test splits.

---

## Topics Covered

- Cross Validation
- 5-Fold Cross Validation
- Average R² Score
- Standard Deviation

---

## Why Cross Validation?

Instead of evaluating the model only once, Cross Validation evaluates it multiple times on different train-test splits.

This provides a more reliable estimate of performance.

---

## Learning

- More reliable model evaluation
- Reduced bias from a single train-test split
- Better estimate of generalization

---

## Outcome

I learned how to use `cross_val_score()` to evaluate a machine learning model across multiple folds.
